从玩家按键到伤害结算的完整调用链路，含 Client / Server / OtherClient 三列泳道

🎯 核心设计：本地预测 + 服务器权威验证
客户端先执行 LocalFire() 做预测性显示（动画/粒子/音效），同时通过 RPC 发送 ServerFire() 给服务器。 服务器收到后通过 MulticastFire() 广播给所有客户端，原始客户端因 IsLocallyControlled && !HasAuthority 检查跳过重复执行。

📋 关键函数调用栈详解

CombatComponent::Fire() — 主入口

void UCombatComponent::Fire()
{
    if (EquippedWeapon == nullptr) return;

    if (CanFire())                              // 三条件检查
    {
        bCanFire = false;                       // 防重复标记
        
        Owner->GetUIComponent()->SetCrosshairShootingFactor(0.75f);

        switch (EquippedWeapon->FireType)       // 根据 FireType 分发
        {
        case EFireType::EFT_Projectile:
            FireProjectileWeapon(); break;
        case EFireType::EFT_HitScan:
            FireHitScanWeapon();   break;
        case EFireType::EFT_Shotgun:
            FireShotgun();         break;
        }
        
        StartFireTimer();                       // 启动冷却
    }
}

CombatComponent::FireHitScanWeapon() — 射线武器分支

void UCombatComponent::FireHitScanWeapon()
{
    if (EquippedWeapon && Owner)
    {
        // ★ 先在本地计算散射偏移（确保客户端和服务器用同一套结果）
        HitTarget = EquippedWeapon->bUseScatter 
            ? EquippedWeapon->TraceEndWithScatter(HitTarget) 
            : HitTarget;
            
        if (!Owner->HasAuthority()) 
            LocalFire(HitTarget);               // ★ 本地预测
            
        ServerFire(HitTarget);                  // ★ 发送给服务器
    }
}

ServerFire → MulticastFire — 网络传播链

// ====== 服务器端实现 ======
void UCombatComponent::ServerFire_Implementation(
    const FVector_NetQuantize& TraceHitTarget)
{
    MulticastFire(TraceHitTarget);             // 收到后立即广播
}

// ====== 多播到所有客户端 ======
void UCombatComponent::MulticastFire_Implementation(
    const FVector_NetQuantize& TraceHitTarget)
{
    // ★ 防重复：跳过发起请求的本地客户端
    // （因为已经执行过 LocalFire 了）
    if (Owner && Owner->IsLocallyControlled() 
        && !Owner->HasAuthority()) return;      // ← 关键！
    
    LocalFire(TraceHitTarget);                 // 其他客户端执行
}

CombatComponent::LocalFire() — 本地预测执行

void UCombatComponent::LocalFire(
    const FVector_NetQuantize& TraceHitTarget)
{
    if (EquippedWeapon == nullptr) return;
    
    if (Owner && CombatState == ECombatState::ECS_Unoccupied)
    {
        Owner->PlayFireMontage(bAiming);        // 播放角色开火动画
        EquippedWeapon->Fire(TraceHitTarget);   // 调用武器的 Fire()
        // → HitScan: 射线检测+伤害+特效
        // → Projectile: 生成投射物[仅Server]
        // → Shotgun: 多弹丸检测+聚合伤害
    }
}
✅ 数据流完整性保证
  • FVector_NetQuantize: 使用网络量化向量压缩传输，减少带宽消耗
  • Reliable RPC: ServerFire/MulticastFire 均使用 Reliable 保证不丢包
  • bUseScatter 散射计算在 Client 端先执行: 确保 LocalFire 和 ServerFire 使用同一组随机值

📍 HitScanWeapon::Fire() 完整实现

void AHitScanWeapon::Fire(const FVector& HitTarget)
{
    Super::Fire(HitTarget);                     // 基类: 动画+弹壳+SpendRound

    APawn* OwnerPawn = Cast(GetOwner());
    if (OwnerPawn == nullptr) return;
    AController* InstigatorController = OwnerPawn->GetController();

    const USkeletalMeshSocket* MuzzleFlashSocket = 
        GetWeaponMesh()->GetSocketByName("MuzzleFlash");
    if (MuzzleFlashSocket)
    {
        FTransform SocketTransform = MuzzleFlashSocket->GetSocketTransform(GetWeaponMesh());
        FVector Start = SocketTransform.GetLocation();

        FHitResult FireHit;
        WeaponTraceHit(Start, HitTarget, FireHit);     // ★ 执行射线检测

        AXMBCharacterBase* BlasterCharacter = Cast(FireHit.GetActor());
        if (OwnerPawn != BlasterCharacter)              // 不能打自己
        {
            if (BlasterCharacter && HasAuthority() && InstigatorController)
            {
                // ★★★ 仅服务器端执行伤害！★★★
                UGameplayStatics::ApplyDamage(
                    BlasterCharacter,
                    Damage,                             // 默认 20.f
                    InstigatorController,
                    this,
                    UDamageType::StaticClass()
                );
            }
        }
        
        // 以下特效在所有客户端都播放（视觉层）
        if (ImpactParticles)  { /* 生成命中点粒子 */ }
        if (HitSound)         { /* 播放命中音效 */ }
        if (MuzzleFlash)      { /* 生成枪口火焰 */ }
        if (FireSound)        { /* 播放射击音效 */ }
    }
}

🚀 ProjectileWeapon::Fire() 完整实现

void AProjectileWeapon::Fire(const FVector& HitTarget)
{
    // 步骤1: 执行基类的通用开火逻辑（动画/弹壳/扣弹药）
    Super::Fire(HitTarget);

    // 步骤2: ★ 仅服务器端生成投射物 ★
    // 客户端不需要自行生成——服务器的投射物通过 bReplicates 自动同步
    if (!HasAuthority()) return;                  // ← 关键！
    
    const USkeletalMeshSocket* MuzzleFlashSocket = 
        GetWeaponMesh()->GetSocketByName("MuzzleFlash");
    if (MuzzleFlashSocket)
    {
        FTransform SocketTransform = MuzzleFlashSocket->GetSocketTransform(GetWeaponMesh());
        
        // 计算射击方向
        FVector ToTarget = HitTarget - SocketTransform.GetLocation();
        FRotator TargetRotation = ToTarget.Rotation();

        if (ProjectileClass)
        {
            FActorSpawnParameters SpawnParams;
            SpawnParams.Owner = GetOwner();
            SpawnParams.Instigator = InstigatorPawn;

            // 步骤3: 在枪口位置生成投射物
            AProjectile* Projectile = World->SpawnActor(
                ProjectileClass,
                SocketTransform.GetLocation(),
                TargetRotation,
                SpawnParams
            );
            // 投射物会自动通过网络复制到所有客户端 (bReplicates=true)
        }
    }
}
✅ 设计优势：投射物的网络同步完全由引擎管理
因为 AProjectile::bReplicates = true，服务器 Spawn 后引擎会自动将位置/旋转/速度同步到所有客户端，无需手动 RPC。

💥 ShotGun::FireShotgun() 完整实现

void AShotGun::FireShotgun(const TArray& HitTargets)
{
    AWeaponBase::Fire(FVector());              // 基类动画+弹壳

    APawn* OwnerPawn = Cast(GetOwner());
    if (OwnerPawn == nullptr) return;
    AController* InstigatorController = OwnerPawn->GetController();

    const USkeletalMeshSocket* MuzzleFlashSocket = 
        GetWeaponMesh()->GetSocketByName("MuzzleFlash");
    if (MuzzleFlashSocket)
    {
        FTransform SocketTransform = MuzzleFlashSocket->GetSocketTransform(GetWeaponMesh());
        FVector Start = SocketTransform.GetLocation();

        TMap HitMap;  // ★ 命中统计表

        for (auto HitTarget : HitTargets)          // 循环每个弹丸
        {
            FHitResult FireHit;
            WeaponTraceHit(Start, HitTarget, FireHit);  // 射线检测

            AXMBCharacterBase* BlasterCharacter = Cast(FireHit.GetActor());
            if (BlasterCharacter)
            {
                // ★ 聚合同一目标的命中次数
                if (HitMap.Contains(BlasterCharacter))
                    HitMap[BlasterCharacter]++;      // 再次命中
                else
                    HitMap.Emplace(BlasterCharacter, 1); // 首次命中

                // 每颗弹丸都有独立的命中特效和音效
                if (ImpactParticles) { /* 生成命中粒子 */ }
                if (HitSound)         { /* 播放命中音效 */ }
            }
        }

        // ★ 统一计算伤害：基础伤害 × 命中弹丸数
        for (auto HitPair : HitMap)
        {
            if (HitPair.Key && HasAuthority() && InstigatorController)
            {
                UGameplayStatics::ApplyDamage(
                    HitPair.Key,
                    Damage * HitPair.Value,           // 伤害 × 命中数
                    InstigatorController,
                    this,
                    UDamageType::StaticClass()
                );
            }
        }
    }
}

TraceEndWithScatter 的球面随机偏移构造与几何示意图

🎯 为什么需要散射？
如果每次开火都用完全相同的准心瞄准点，射击会过于精准（"激光枪"）。引入散射模拟真实武器的弹道散布——距离越远、散布越大。

🔍 散射原理可视化

● 枪口 (Start)

\
 \
  \
   \___________ _________________ ━━━ ⭕ 散射球面 (半径=75)
              \  ○ SphereCenter    \
               \                      \
                \                      ● EndLoc (随机)
                 \                        \
                  \________________________\______ TRACE_LENGTH → ● 最终终点


  ↑ DistanceToSphere=800                          ↑ 最大射线长度=80000


┌─────────────────────────────────────────────────────────────────┐
│  散射公式:                                                       │
│  1. ToTargetNormalized = (HitTarget - Start).GetSafeNormal()     │
│  2. SphereCenter = Start + ToTargetNormalized × 800             │
│  3. RandomVec = RandomUnitVector() × RandRange(0, 75)          │
│  4. EndLoc = SphereCenter + RandomVec                           │
│  5. ToEndLoc = EndLoc - Start                                   │
│  6. 返回 = Start + ToEndLoc × 80000 / |ToEndLoc|                │
└─────────────────────────────────────────────────────────────────┘

💻 TraceEndWithScatter 完整实现

FVector AWeaponBase::TraceEndWithScatter(const FVector& HitTarget)
{
    // 获取枪口插槽的世界坐标
    const USkeletalMeshSocket* MuzzleFlashSocket = 
        GetWeaponMesh()->GetSocketByName("MuzzleFlash");
    if (MuzzleFlashSocket == nullptr) return FVector();
    
    FTransform SocketTransform = MuzzleFlashSocket->GetSocketTransform(GetWeaponMesh());
    FVector Start = SocketTransform.GetLocation();          // ① 起点
    
    // 计算从枪口到目标的单位方向向量
    FVector ToTargetNormalized = (HitTarget - Start).GetSafeNormal();  // ② 归一化
    
    // 在瞄准方向上 DistanceToSphere(800) 单位处建立散射球心
    FVector SphereCenter = Start + ToTargetNormalized * DistanceToSphere;  // ③
    
    // ★ 在球面上取一个随机点：单位随机向量 × [0, SphereRadius]
    FVector RandomVec = UKismetMathLibrary::RandomUnitVector() 
        * FMath::FRandRange(0.f, SphereRadius);             // ④ 随机偏移
    
    FVector EndLoc = SphereCenter + RandomVec;             // ⑤ 偏移后的终点
    FVector ToEndLoc = EndLoc - Start;                     // ⑥ 到偏移点的向量
    
    // 将射线延伸到 TRACE_LENGTH(80000)，保持相同的偏移角度
    return FVector(Start + ToEndLoc * TRACE_LENGTH / ToEndLoc.Size());  // ⑦
}

🎯 ShotgunTraceEndWithScatter — 多弹丸版本

void AShotGun::ShotgunTraceEndWithScatter(
    const FVector& HitTarget, 
    TArray& HitTargets)
{
    const USkeletalMeshSocket* MuzzleFlashSocket = 
        GetWeaponMesh()->GetSocketByName("MuzzleFlash");
    if (MuzzleFlashSocket == nullptr) return;
    
    FTransform SocketTransform = MuzzleFlashSocket->GetSocketTransform(GetWeaponMesh());
    FVector Start = SocketTransform.GetLocation();
    
    FVector ToTargetNormalized = (HitTarget - Start).GetSafeNormal();
    FVector SphereCenter = Start + ToTargetNormalized * DistanceToSphere;

    // ★ 循环生成 NumberOfPellets(10) 个独立的散射终点
    for (uint32 i = 0; i < NumberOfPellets; i++)
    {
        FVector RandomVec = UKismetMathLibrary::RandomUnitVector() 
            * FMath::FRandRange(0.f, SphereRadius);     // 每颗弹丸独立随机
        FVector EndLoc = SphereCenter + RandomVec;
        FVector ToEndLoc = EndLoc - Start;

        ToEndLoc = Start + ToEndLoc * TRACE_LENGTH / ToEndLoc.Size();
        
        HitTargets.Add(ToEndLoc);                       // 加入数组传给服务器
    }
}

关键设计决策总结

架构选择的原因、已知 TODO/BUG 清单与优化建议

🏗️ 架构设计决策

🎯 本地预测（LocalFire）

做法：客户端在发送 RPC 之前先执行 LocalFire() 播放本地效果。

目的：消除网络延迟感知。玩家按下左键后立即看到/听到反馈，无需等待服务器往返。

代价：需要防重复机制（IsLocallyControlled 检查），且客户端看到的弹道可能与服务器最终判定不一致。

🛡️ 服务器权威保护

做法：所有 ApplyDamage() 和 SpawnActor<Projectile>() 都包裹在 if (HasAuthority()) 内。

目的：防止作弊。客户端无法伪造伤害或非法生成投射物。

覆盖范围：HitScan::Fire / Shotgun::FireShotgun / Projectile::Fire / Projectile::OnHit

🔒 COND_OwnerOnly 安全策略

做法：CarriedAmmo 使用 COND_OwnerOnly 条件复制。

目的：隐藏敏感信息（弹药库存），防止信息泄露型作弊。

额外收益：减少不必要的网络流量（不需要把每个人的弹药发给所有人）。

🔄 防重复机制

做法：MulticastFire_Implementation() 中检查： if (Owner->IsLocallyControlled() && !Owner->HasAuthority()) return;

目的：避免发起请求的客户端执行两次（一次 LocalFire，一次 MulticastFire）。

注意：Host（Listen Server）模式下 IsLocallyControlled 和 HasAuthority 同时为 true，不会触发此检查——这是正确的。

🎲 散射在客户端先算

做法：FireHitScanWeapon() 中先调用 TraceEndWithScatter() 再分别传给 LocalFire 和 ServerFire。

目的：保证客户端和服务器的散射随机值一致（同一帧计算）。

潜在风险：恶意客户端可能修改 HitTarget 参数绕过散射，直接发送精确坐标。

📦 投射物引擎托管同步

做法：设置 AProjectile::bReplicates = true+SetReplicateMovement(true)。

目的：无需手动编写投射物的位置同步 RPC，引擎自动处理。

优势：简化代码，且引擎的网络优先级/插值/回滚机制都能正常工作。
